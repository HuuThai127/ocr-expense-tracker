5. TECHNICAL CHALLENGES & RESOLUTIONS

Challenge 1: Unifying Vietnamese Currency Notations in OCR Text

  • The Problem: Vietnamese paper receipts utilize varied thousand and decimal formats (e.g. 150.000 đ, 150,000 VND, 1.250.000). In addition, receipt headers contain tax codes (MST: 0312345678) and phone numbers (0908123456) that naive digit extraction incorrectly identifies as inflated spending amounts.
  • The Solution: Implemented a 3-priority extraction algorithm in ReceiptParser: (1) Reverse scan for total keywords (TONG CONG, THANH TIEN, TOTAL) and parse trailing numbers; (2) Scan for lines ending in currency indicators (VND, VNĐ, đ); (3) Noise rejection regex (\b0[35789]\d{8}\b, MST, TEL) preventing tax and phone numbers from entering monetary candidate arrays.

Challenge 2: High-Performance Animated Charts Without Third-Party Libraries

  • The Problem: Prohibiting third-party libraries (such as fl_chart) required writing bespoke math for animated Donut and Bar charts, including slice hit-testing, dynamic normalization, and smooth segment animations.
  • The Solution:
    • Built CategoryDonutPainter with drawArc() driven by a 900ms CurvedAnimation(curve: Curves.easeOutCubic).
    • Implemented angular bisector displacement ($d = 6\text{px}$) so selected slices pop outward dynamically while the center hole displays the active category icon, percentage, and exact amount.
    • Built WeeklyBarPainter normalizing daily expenditures against peak spending with 20% visual headroom.

Challenge 3: Multi-Platform Test Portability & Evaluation Readiness

  • The Problem: Google ML Kit Text Recognition is a native Android/iOS mobile library that lacks native binary runtime on desktop CI environments, and physical camera sensors are unavailable on emulators or desktop test machines.
  • The Solution:
    • Decoupled widget tests using a FakeExpenseDao to eliminate native SQLite thread locks during headless testing.
    • Verified database CRUD logic with in-memory SQLite instances in test/database/database_test.dart.
    • Added a built-in Sample Receipt Suite directly in CameraCaptureScreen, enabling grading evaluators to test camera, crop, and OCR parsing pipelines seamlessly on any machine.
